# 仿真器

> 机器人仿真平台

## 平台对比

| 仿真器 | 特点 | 适用场景 |
|--------|------|---------|
| Isaac Sim | GPU 加速、ROS 集成 | 通用机器人 |
| Isaac Gym | 并行训练、RL 优化 | 大规模 RL |
| MuJoCo | 快速、精确物理 | 运动控制 |
| PyBullet | 轻量、Python 友好 | 快速原型 |
| Gazebo | ROS 原生、成熟生态 | 真机前验证 |
| SAPIEN | 关节物体交互 | 操作任务 |
