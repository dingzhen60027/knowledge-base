# 机械臂 Peg-in-Hole 装配控制方法综述

> 从传统规控到前沿学习方法的完整梳理。核心线索：不是追求"更精确的定位"，而是解决"接触过程中的自适应修正"。

## 一、问题定义：Peg-in-Hole 到底难在哪

Peg-in-Hole（轴孔装配）是制造业中最基本的装配操作之一：将一根轴（peg）插入一个孔（hole）中。

听起来简单，但它实际上是机器人装配领域被研究了几十年的 benchmark 问题。

### 为什么难

| 误差来源 | 说明 |
| -------- | ---- |
| 视觉标定误差 | 相机到机器人的手眼标定永远有残差 |
| 相机识别误差 | 光照、遮挡、孔位特征不明显 |
| 机械臂重复定位误差 | 绝对定位精度通常不如重复精度 |
| 末端夹具误差 | 抓取偏差、夹具刚度影响 |
| 孔轴间隙 | 紧配合时间隙可能只有几十微米 |
| 接触摩擦不确定性 | 材料、表面粗糙度、润滑条件都会影响 |

### 真正的核心问题

> [!important]
> Peg-in-Hole 的核心挑战不是"孔在哪里"，而是**接触之后怎么办**。

视觉可以把 peg 带到孔口附近（毫米级），但从孔口接触到成功插入这最后几毫米，涉及复杂的接触状态：单边接触、双边接触、倾斜卡滞、摩擦突变。**这才是 peg-in-hole 真正难的地方。**

## 二、传统规控方法：前人是怎么解决的

传统规控方法的整体思路可以概括为：

```
视觉/标定粗定位 → 规划接近轨迹 → 接触检测 → 力觉判断偏差 → 规则搜索/柔顺修正 → 插入完成
```

核心不是"学习"，而是依靠**几何定位、轨迹规划、力/力矩反馈、柔顺控制和规则搜索**来完成插孔。

### 2.1 视觉/标定粗定位

机械臂首先通过相机、夹具标定或工装定位获得孔的大致位置，依靠几何关系和坐标变换：

$$
{}^{B}T_{H} = {}^{B}T_{C} \cdot {}^{C}T_{H}
$$

式中，${}^{B}T_{H}$ 为孔在机器人基坐标系下的位姿，${}^{B}T_{C}$ 为相机到基座的变换矩阵，${}^{C}T_{H}$ 为孔在相机坐标系下的位姿。

这一阶段的目标是把 peg 移动到孔口附近，但由于前述误差，通常不能保证一次准确插入。

### 2.2 接近与预接触

机械臂按规划轨迹移动到孔口上方，沿插入方向缓慢下降。实时监测末端力/力矩信号：

$$
F_z > F_{\text{th}}
$$

当插入力超过阈值时，认为 peg 已与孔口或工件表面发生接触。此时停止快速下压，进入力控搜索阶段。

### 2.3 螺旋搜索

最经典的方法。当视觉定位不能保证 peg 正好对准孔时，机械臂在孔口附近做小范围平面搜索，同时缓慢施加向下插入力：

$$
x(t)=x_0 + r(t)\cos(\omega t)
$$

$$
y(t)=y_0 + r(t)\sin(\omega t)
$$

$$
r(t)=kt
$$

式中，$(x_0,y_0)$ 为初始估计孔位，$r(t)$ 为搜索半径，$\omega$ 为角速度，$k$ 为半径增长系数。

> [!note] 螺旋搜索逻辑简单、工程上容易调试，但效率不高，对参数敏感，接触过程中可能产生较大摩擦和碰撞。

### 2.4 阻抗控制

阻抗控制是 peg-in-hole 中最常用的力控方法。它不是严格跟踪位置，而是让机械臂在接触时表现得像一个"弹簧—阻尼—质量"系统：

$$
M_d(\ddot{x}-\ddot{x}_d)+D_d(\dot{x}-\dot{x}_d)+K_d(x-x_d)=F_{\text{ext}}
$$

式中，$M_d$ 为期望惯量，$D_d$ 为期望阻尼，$K_d$ 为期望刚度，$x_d$ 为期望轨迹，$F_{\text{ext}}$ 为外部接触力。

在 peg-in-hole 中，沿插入方向可设低刚度使 peg 柔顺下插，横向可设适当刚度使 peg 被孔壁接触力引导回中心。

### 2.5 导纳控制

导纳控制与阻抗控制相近，但实现方式不同：根据测得的外力计算位置/速度修正量，再发送给位置控制器：

$$
M_d\Delta \ddot{x}+D_d\Delta \dot{x}+K_d\Delta x=F_{\text{ext}}
$$

最终控制指令：

$$
x_{\text{cmd}} = x_d + \Delta x
$$

> [!tip] 导纳控制特别适合底层只开放位置控制接口的工业机械臂。

### 2.6 基于力/力矩规则的状态机

很多传统方法将装配过程分解为有限状态机：

$$
S=\{S_1,S_2,S_3,S_4,S_5\}
$$

| 状态 | 含义 | 切换条件 |
| ---- | ---- | -------- |
| $S_1$ | 接近孔口 | 位置到达 |
| $S_2$ | 接触检测 | $F_z > F_{\text{th}}$ |
| $S_3$ | 平面搜索 | $\mid F_x \mid > F_{x,\text{th}}$ 或 $\mid F_y \mid > F_{y,\text{th}}$ |
| $S_4$ | 姿态修正 | $\mid M_x \mid > M_{x,\text{th}}$ 或 $\mid M_y \mid > M_{y,\text{th}}$ |
| $S_5$ | 插入完成 | $z < z_{\text{target}}$ 且 $F_z < F_{\text{safe}}$ |

> [!warning] 状态机方法工程可解释性强，安全边界清楚，但规则依赖人工经验，换孔径、换材料、换摩擦条件后往往需要重新调参。

### 2.7 远程中心柔顺（RCC）

RCC（Remote Center Compliance）不是依靠算法，而是在末端夹具上设计被动柔顺结构，使 peg 在接触孔边时能自动产生微小倾斜和平移，被动对准孔。

**核心思想**：通过机械结构提供柔顺性，让装配误差在接触过程中自动释放。

RCC 的优点是稳定、实时性好、不依赖复杂计算；缺点是适应范围有限，结构需针对具体任务设计。

### 2.8 传统方法的优势与局限

| 优势 | 局限 |
| ---- | ---- |
| 可解释性强 | 依赖人工调参 |
| 安全性好（力阈值、速度限制明确） | 对环境变化适应性有限 |
| 工程实现成熟 | 效率与精度难以同时兼顾 |
| 稳定性高 | 复杂接触状态难建模 |

## 三、问题升华：传统方法为什么不够

传统规控在**确定环境**下可靠，但真实装配场景中存在几个它很难处理的维度：

**第一，依赖人工调参。** 阻抗参数、搜索半径、力阈值、速度、状态切换条件都需要人工设定。工程师需要针对具体孔径、材料和间隙反复调试。

**第二，对环境变化适应性有限。** 孔位误差、摩擦系数、装配间隙或工件姿态变化较大时，原有规则可能不再适用。换一个批次的零件，之前调好的参数可能要重新调。

**第三，效率和精度难以同时兼顾。** 搜索范围大可以提高成功率但降低效率；搜索步长小可以提高精度但耗时更长。这是一个内在 trade-off，单靠固定规则很难动态平衡。

**第四，复杂接触状态难建模。** Peg-in-hole 中存在单边接触、双边接触、卡滞、倾斜、摩擦突变等多种情况，传统规则很难完整覆盖所有组合。

> [!important] 传统规控的瓶颈不在于"定位不够准"，而在于**接触之后的自适应修正能力不足**。这为 learning-based 方法提供了真正有意义的研究切入点。

## 四、Learning-based 到底有没有意义：直面核心问题

这是一个必须正面回答的问题。如果 learning-based 被理解为"比传统方法更精确地定位孔中心"，那它确实意义不大——视觉标定和几何配准在这方面已经做得很好了。

### 4.1 不要说什么

> "使用强化学习提高定位精度。"

这句话站不稳。强化学习不天然等于高精度。

### 4.2 要说的是什么

Learning-based 的真正意义在于四个方面：

**第一，减少人工规则设计。** 传统方法需要人为规定"力大了往哪边修""力矩大了怎么调姿态"，这些规则很难写全。学习方法从数据中学习状态到动作的映射：

$$
\Delta x = \pi_{\theta}(s)
$$

其中 $s$ 可包括视觉误差、末端位姿、插入力、侧向力、力矩和插入深度。策略不是靠人为枚举所有接触情况，而是从数据中学习复杂接触信号与修正动作之间的关系。

**第二，提高对不确定性的适应能力。** 传统规控假设误差范围和接触模型比较稳定。学习策略如果训练时覆盖了不同初始偏差、不同摩擦、不同间隙和不同姿态误差，就可能学到更泛化的修正规律——不是让单次定位精度更高，而是让系统在更多工况下成功插入。

**第三，多目标优化。** 传统规控靠人工调参平衡成功率、速度和插入力。强化学习可以把这些目标写进奖励函数同时优化：

$$
r = r_{\text{success}} - \lambda_1 |F| - \lambda_2 t - \lambda_3 |\Delta a|
$$

策略优化的不仅是"能不能插进去"，还包括"插入力是否小""时间是否短""动作是否平滑"。

**第四，把专家经验变成可泛化策略。** 传统方法的经验在工程师脑子里，换一个场景就要重新调试。模仿学习可以把示教数据转化为策略网络，让经验可复制、可迁移。

### 4.3 正确的研究定位

> [!important]
> **本文不将强化学习作为单独的高精度定位方法，而是将其作为视觉—力控框架中的策略优化模块。视觉用于粗定位，力控用于安全接触和柔顺插入，强化学习用于在接触不确定条件下学习微调动作或自适应阻抗参数，从而提高插入成功率、降低插入力峰值并增强对初始位姿偏差的适应能力。**

## 五、具体 Learning-based 方案设计

### 5.1 整体框架

```
视觉模块 → 粗定位 → 基础轨迹规划
                        ↓
                  x_ref + Δx_learned = x_cmd → 机械臂
                        ↑                    ↓
                  学习策略 ← 状态(s) ← 力/力矩传感器
```

关键设计原则：

> **"传统控制 + 学习补偿"** —— 底层仍由位置控制/阻抗控制保证安全，学习模块只输出微小修正量或参数调节量。

### 5.2 为什么是 IL + RL，而不是纯 RL

纯强化学习从零开始在 peg-in-hole 中探索有两个严重问题：

| 问题 | 说明 |
| ---- | ---- |
| 探索效率低 | 机械臂在孔口附近反复碰撞、卡住，大量无效探索 |
| 奖励稀疏 | 只有成功插入才有明显正反馈，训练极难稳定 |

> [!tip] 模仿学习先让策略学会"像人一样大致会插"的初始行为，强化学习再在此基础上优化插入力、插入时间和成功率。

**技术路线：先模仿学习预训练，再强化学习微调。**

### 5.3 行为克隆预训练

采集专家示教数据（人工遥操作、拖动示教、传统力控搜索轨迹、仿真专家策略），数据包括视觉图像、孔位偏差、末端位姿、六维力/力矩、插入深度和对应动作。

$$
\pi_{\theta}(a_t|s_t) \approx \pi_E(a_t|s_t)
$$

行为克隆损失函数：

$$
L_{BC}=\frac{1}{N}\sum_{t=1}^{N}\left|a_t-\pi_{\theta}(s_t)\right|^2
$$

### 5.4 强化学习微调

将预训练策略作为 RL 的初始策略，用 PPO、SAC 或 DDPG 继续微调：

$$
\theta^{*}=\arg\max_{\theta}\mathbb{E}_{\pi_{\theta}}\left[\sum_{t=0}^{T}\gamma^t r_t\right]
$$

RL 不是从零探索，而是在模仿学习给出的可行策略附近继续优化，成功率和训练稳定性都更好。

### 5.5 两种动作空间设计

**方案 A：输出位置修正量**

$$
x_{cmd}=x_{ref}+\Delta x_{IL+RL}
$$

学习策略输出小范围修正量，不直接控制大范围运动。适合工业机械臂的位置控制接口。

**方案 B：输出阻抗/导纳参数**（更有研究价值）

$$
K_d, D_d = \pi_{\theta}(s_t)
$$

学习策略不直接控制位置，而是根据状态自适应调整柔顺参数。底层仍由阻抗控制保证安全，可解释性和安全性更好。

也可以输出导纳目标力：

$$
w_t = \pi_{\theta}(s_t)
$$

$$
M_d\Delta\ddot{x}+D_d\Delta\dot{x}+K_d\Delta x = w_t
$$

### 5.6 奖励函数设计

$$
r = r_{\text{success}} - \lambda_1|F| - \lambda_2|e_p| - \lambda_3|\Delta a| - \lambda_4 t
$$

| 项 | 含义 |
| --- | ---- |
| $r_{\text{success}}$ | 成功插入奖励 |
| $|F|$ | 接触力惩罚（越小越好） |
| $|e_p|$ | 位置误差惩罚 |
| $|\Delta a|$ | 相邻动作变化量惩罚（鼓励平滑） |
| $t$ | 时间惩罚（鼓励效率） |

### 5.7 建议论文结构

| 章节 | 内容 |
| ---- | ---- |
| 第1章 绪论 | 研究背景、Peg-in-Hole 任务、视觉引导、力控、学习控制综述 |
| 第2章 任务建模与传感分析 | 运动学模型、接触状态分析、插入力变化规律、视觉与力觉角色 |
| 第3章 视觉—力觉融合控制框架 | 整体框架设计：粗定位 + 力觉接触 + 阻抗控制 + 学习模块 |
| 第4章 基于模仿与强化学习的插入策略 | 状态/动作空间、BC预训练、RL微调、网络结构、训练流程 |
| 第5章 仿真与实验验证 | 不同偏差/间隙/摩擦工况下的对比实验 |
| 第6章 总结与展望 | Sim-to-real、复杂装配、多孔装配、自适应力控 |

## 六、前沿研究方向：不是简单组合，而是解决本质问题

近两年的前沿文献不是在简单地"视觉 + 力控 + RL"组合，而是在解决几个更本质的问题：**接触状态不可观测、策略泛化差、RL 样本效率低、传统力控参数固定、示教数据不精确、复杂孔型难处理**。

### 6.1 力域扩散策略：输出 6D 力/力矩而非位置

**TacDiffusion**（2024）提出用扩散模型直接生成六维力/力矩动作，用于高精度触觉插入任务。关键创新：不是让策略输出末端位置修正，而是让策略学习"该施加什么样的力/力矩模式"，更贴近 peg-in-hole 的接触本质。^[[arXiv:2409.11047](https://arxiv.org/html/2409.11047v1)]

$$
w_t = \pi_{\theta}(s_t)
$$

式中 $w_t=[F_x,F_y,F_z,M_x,M_y,M_z]$ 为策略输出的六维力/力矩指令。

> [!tip] 这比"RL 输出 $\Delta x$"更有新意，因为它直接操作接触力的维度。

### 6.2 扩散模型 + 分层强化学习

**Diffusion-guided hierarchical RL with admittance control**（2026）用扩散模型给出更合理的动作分布或子策略先验，再用分层强化学习处理多孔插入任务。核心理念：不是让 RL 盲目探索，而是用生成模型提供"可能成功的接触动作先验"。^[[ScienceDirect](https://www.sciencedirect.com/science/article/abs/pii/S0278612526000804)]

$$
z_t \sim p_{\phi}(z_t|s_t)
$$

$$
a_t = \pi_{\theta}(s_t, z_t)
$$

式中 $p_{\phi}$ 为扩散模型生成的候选动作或技能隐变量，$\pi_{\theta}$ 为 RL 策略。

### 6.3 元强化学习 Meta-RL：跨工况快速适应

**Context-Based Meta RL for Robust Peg-in-Hole**（2024）解决的核心问题：不是单次能不能插进去，而是**任务参数变了还能不能适应**。当孔位置、姿态等存在不确定时，通过上下文信息让策略快速适应新任务。^[[arXiv:2409.16208](https://arxiv.org/html/2409.16208v4)]

$$
a_t = \pi_{\theta}(s_t, c_t)
$$

式中 $c_t$ 为由历史接触数据推断出的任务上下文（孔位偏差、摩擦状态、装配间隙或接触模式）。

> [!important] 普通 RL 学的是"一个孔位分布下的策略"，Meta-RL 学的是"如何快速适应新的孔位偏差/摩擦/姿态误差"。

### 6.4 人类技能分层模仿：学习"感知—决策—操作"链条

**Multi-level imitation model**（2025）不只模仿轨迹，而是把人类装配技能建模为多层马尔可夫决策过程，学习人的 perception-decision-operation 技能。^[[ScienceDirect](https://www.sciencedirect.com/science/article/abs/pii/S0736584524001947)]

$$
m_t = f_{\phi}(s_t)
$$

$$
a_t = \pi_{\theta}(s_t, m_t)
$$

式中 $m_t$ 表示装配阶段或接触模式，$f_{\phi}$ 识别当前处于孔口接触、边缘接触、卡滞还是成功插入。

这个方向特别适合 peg-in-hole，因为插入过程天然分阶段，真正难的不是每一步轨迹，而是**什么时候判断进入哪个阶段，以及该采取哪类操作**。

### 6.5 力时序特征识别：1D-CNN/GRU 判断接触状态

**Learning-based peg insertion with 1D-CNN and GRU**（2025）从力/力矩时间序列中提取特征，识别 peg 与 hole 之间的不同接触状态。^[[ScienceDirect](https://www.sciencedirect.com/science/article/pii/S2667379724000676)]

核心洞察：接触状态不是一个瞬时力值能判断的，要看一段时间内的力/力矩变化趋势。传统规控用瞬时阈值：

$$
F_z > F_{\text{th}}
$$

但学习方法可以输入一段力觉序列：

$$
\mathcal{F}_{t-H:t} = \{F_{t-H}, F_{t-H+1}, \ldots, F_t\}
$$

并输出接触状态：

$$
m_t = g_{\phi}(\mathcal{F}_{t-H:t})
$$

这能识别滑动、卡滞、偏心、倾斜等动态接触模式，比简单的阈值判断强得多。

### 6.6 视觉—触觉融合 + SAC

**Visual-Tactile Fusion and SAC-Based Learning**（2025）把视觉和触觉融合后用于 SAC 强化学习，应对姿态偏差、不同 peg 形状和环境噪声。实验显示在成功率、完成时间和跨形状泛化方面有改进。^[[MDPI Machines](https://www.mdpi.com/2075-1702/13/7/605)]

### 6.7 程序生成 + 域随机化：为泛化而非单一最优

**Procedural Generation for Peg-in-Hole**（2024）通过大量随机生成的装配场景训练 RL 策略，提高在不同场景下的泛化和适应能力。^[[ORBilu](https://orbilu.uni.lu/bitstream/10993/62517/1/procgen_for_peg_in_hole_assembly.pdf)]

$$
\xi \sim p(\xi)
$$

$$
\pi_{\theta}^{*} = \arg\max_{\theta}\mathbb{E}_{\xi}\left[\sum_{t=0}^{T}\gamma^t r_t\right]
$$

式中 $\xi$ 为随机化的任务参数（孔位误差、摩擦系数、装配间隙、传感器噪声等）。传统规控在固定工装下很好，但一换场景就要重新调参。域随机化故意在训练中随机化各种条件，使策略学到更鲁棒的插入行为。

### 六个前沿方向的共同主线

| 方向 | 解决的本质问题 |
| ---- | -------------- |
| 力域扩散策略 | 动作空间不该是位置，应该是力 |
| 扩散 + 分层 RL | RL 探索效率低，需要生成模型提供先验 |
| Meta-RL | 换一个孔/偏差，策略就失效 |
| 分层模仿学习 | 示教数据不只是轨迹，还有决策逻辑 |
| 力时序识别 | 接触状态不是瞬时量，是时序模式 |
| 域随机化 | 不是为了单一最优，是为了泛化 |

## 七、如何让课题不俗套：三种前沿方案

不要写成普通的"视觉定位 + 力控 + 强化学习"，这确实非常常规。

### 方案 A：接触状态识别 + 自适应导纳控制

**核心创新**：学习接触模式，而不是直接学习动作。

$$
m_t = g_{\phi}(I_t, \mathcal{F}_{t-H:t})
$$

$$
M_d, D_d, K_d = \pi_{\theta}(m_t, s_t)
$$

先用视觉和力觉序列识别接触状态（偏心、卡滞、倾斜等），再根据接触状态自适应调整导纳/阻抗参数。学习模块的职责不是"往哪动"，而是"当前是什么接触模式 → 应该用什么柔顺参数"。

**优势**：可解释性强，安全边界清楚，与传统力控深度结合。

### 方案 B：模仿学习预训练 + 力域强化学习微调

**核心创新**：策略输出力/力矩或导纳目标，而不是输出末端位置。

$$
w_t = \pi_{\theta}(s_t)
$$

$$
M_d\Delta\ddot{x}+D_d\Delta\dot{x}+K_d\Delta x = w_t
$$

模仿学习预训练给出基本插入策略，RL 在力域进行微调。学习策略和力控深度结合，不是外面套一层 RL。

**优势**：比"RL 输出 Δx"更有新意，且安全问题由底层导纳控制保障。

### 方案 C：扩散策略生成候选动作 + RL 选择/微调

**核心创新**：用 diffusion policy 提供接触动作先验，RL 负责在线适应。

$$
a_t^{0} \sim p_{\phi}(a_t|s_t)
$$

$$
a_t = a_t^{0} + \Delta a_{\theta}
$$

扩散模型学习接触动作的高质量分布，RL 在此分布附近进行小范围优化。这是目前最前沿的方向，样本效率和成功率都会更好。

**优势**：学术新颖性最高，但实现难度也最大。

## 八、总结

### Learning-based 的前沿意义

不在"它能比传统方法定位更准"，而在：

1. **学习接触状态**：用 1D-CNN/GRU 从力觉时序中识别单边接触、双边接触、卡滞、倾斜等复杂接触模式
2. **学习力控参数**：不是人工设定阻抗/导纳参数，而是根据任务上下文自适应调整
3. **学习跨工况适应**：用 Meta-RL 或域随机化让策略在不同孔位偏差、摩擦、间隙下都能工作
4. **用生成模型提高探索效率**：扩散模型提供高质量动作先验，减少盲目探索
5. **用示教学习人类接触操作经验**：分层模仿学习不只学轨迹，而是学"感知—决策—操作"的完整链条

### 建议的研究定位

> **本文采用视觉定位与力控作为基础控制框架，保证装配过程的基本精度和安全性；在此基础上引入模仿学习与强化学习，使机械臂能够从示教数据和交互经验中学习接触阶段的自适应修正策略，从而提高小间隙 Peg-in-Hole 任务在不确定工况下的装配成功率、鲁棒性和插入效率。**

### 建议题目

- **基于视觉—力觉融合与模仿强化学习的机械臂 Peg-in-Hole 装配控制研究**
- **面向 Peg-in-Hole 任务的机械臂视觉力觉融合模仿强化学习控制方法研究**
