# 项目

> 有明确目标和时间线的项目

## 进行中

```dataview
TABLE status, deadline
FROM "项目"
WHERE status = "active"
SORT deadline ASC
```

## 已完成

```dataview
TABLE status, completed
FROM "项目"
WHERE status = "done"
SORT completed DESC
```

## 待启动

```dataview
TABLE status
FROM "项目"
WHERE status = "backlog"
```
