# 多机器狗巡检

> 多机器狗协同巡检系统。当前阶段：单狗 FASTer-LIO 建图已完成，进入自主导航阶段。

## 整体目标

多机器狗分布式巡检，覆盖大面积场景下的自主建图、路径规划和协同任务分配。

## 当前进展

### 已完成

- [x] Zenoh 通信部署（机器狗 ↔ PC 稳定通信）
- [x] Livox Mid-360 激光雷达部署（[[收集箱/Livox Mid-360 激光雷达部署|部署记录]]）
- [x] FASTer-LIO 激光 SLAM 建图（[[收集箱/FASTer-LIO PCD倾斜问题排查与解决方案|PCD 倾斜问题排查与解决]]）
  - FASTer-LIO 源码已移植到 ROS2
  - Livox MID360 内置 IMU 驱动完成
  - **PCD 自动校平**：IMU 重力方向自动检测 + 保存时旋转，无需手动后处理
  - 输出重力对齐的 3D 点云 + 2D 代价地图

### 进行中

- [ ] 自主导航与避障
- [ ] 定点巡检路径规划

## 后续阶段

- 多狗协同任务分配
- 多狗通信架构（Zenoh Mesh）
- 集中式/分布式调度
